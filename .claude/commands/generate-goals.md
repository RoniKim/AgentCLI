# GOALS.md 생성 (AgentCLI 연동용)

당신은 프로젝트 분석 전문가입니다. 대상 프로젝트의 코드베이스를 분석하여 **AgentCLI가 수렴 조건으로 사용할 GOALS.md**를 생성합니다.

## 대상 프로젝트 (필수)

대상 repo 경로: $ARGUMENTS

**중요**: 위 경로가 비어있거나 `$ARGUMENTS` 그대로이면, 반드시 아래 메시지를 출력하고 **즉시 중단**하세요:

```
오류: 대상 프로젝트 경로가 필요합니다.
사용법: /generate-goals <프로젝트 경로>
예시: /generate-goals D:\000.Work\MyProject
```

경로가 주어졌으면 해당 디렉토리가 존재하는지 확인 후 진행합니다.

## GOALS.md란?

GOALS.md는 AgentCLI가 "프로젝트가 언제 완성인지"를 판단하는 수렴 조건입니다.
- **P0 (Must-Have)**: 반드시 달성해야 할 핵심 항목
- **P1 (Should-Have)**: 달성하면 좋은 개선 항목
- AgentCLI는 매 사이클마다 체크박스를 자동 체크하고, 판정 기준 충족 시 `project_complete` 신호를 발생시킵니다.

### 완료 판정 기준 (`goals_completion_level`)

| level | 조건 |
|-------|------|
| `"p0"` | P0 전부 `[x]` |
| `"p1"` | P0 + P1 전부 `[x]` |
| `"all"` (기본) | 파일 내 모든 체크박스 `[x]` |

## 작업 절차

### 1단계: 프로젝트 분석

대상 repo를 탐색하여 다음을 파악하세요:
- 프로젝트 유형, 기술 스택, 현재 완성도
- 동작하는 기능 vs 미완성 기능
- 빌드/테스트 상태 (성공/실패/미설정)
- 기존 `.doc/GOALS.md`가 있는지 확인
- 기존 `.doc/Docs/` 설계문서가 있으면 참조

### 2단계: 기존 GOALS.md 확인

- **파일이 이미 존재하면**: 내용을 읽고, 아래 중 택일:
  - 항목이 이미 충분하고 적절하면 → "기존 GOALS.md가 적절합니다. 변경하지 않습니다." 출력 후 종료
  - 보강이 필요하면 → 기존 항목 유지 + 새 항목 추가 (기존 체크 상태 보존)
- **파일이 없으면**: 새로 생성

### 3단계: GOALS.md 생성/업데이트

대상 repo의 `.doc/GOALS.md`에 아래 형식으로 작성합니다.

```markdown
# Project Goals

> Generated by Claude Code for AgentCLI.
> 사용자 검토 후 수정하세요. AgentCLI는 이 파일을 기준으로 완성도를 평가합니다.

## P0 (Must-Have)
- [ ] (핵심 기능 1 — 구체적이고 검증 가능한 문장)
- [ ] (핵심 기능 2)
- [ ] (빌드 성공)
- [ ] (런타임 크래시 없음)

## P1 (Should-Have)
- [ ] (개선 사항 1)
- [ ] (개선 사항 2)

## Completion Criteria
- 모든 P0 항목 [x] 완료
- 빌드/테스트 게이트 통과
- 실패 후 미처리 태스크 0개
```

## 항목 작성 규칙

### P0 항목 (5~10개 권장)

1. **구체적**: "성능 개선" ✗ → "메인 페이지 로딩 3초 이내" ✓
2. **검증 가능**: 코드/빌드/테스트로 확인할 수 있는 항목만
3. **AgentCLI가 실행 가능**: Dev 에이전트가 코드로 해결할 수 있는 범위
4. **현재 미완성인 항목만**: 이미 동작하는 기능은 제외
5. **우선순위 반영**: 가장 중요한 것부터 나열
6. **빌드/테스트 항목 필수 포함**: 프로젝트에 빌드/테스트가 있으면 반드시 포함

### P1 항목 (3~7개 권장)

1. 코드 품질 개선 (리팩토링, 중복 제거)
2. 성능 최적화
3. 문서화
4. 테스트 커버리지 확대
5. UX/UI 개선
6. 에러 핸들링 강화

### 금지 사항

- 이미 완성된 기능을 P0에 넣지 마세요
- 외부 서비스 의존 항목 (API 키 발급, 클라우드 배포 등) 제외
- 사용자 결정이 필요한 항목 ("디자인 선택") 제외
- 너무 크거나 모호한 항목 제외 — 하나의 태스크로 완료 가능한 크기로 분해

## AgentCLI 체크박스 자동 매칭

AgentCLI는 태스크 완료 시 GOALS.md 항목과 3-Tier 매칭으로 자동 체크합니다:

1. **정확 매칭**: 태스크에 `GOALS: {항목}` 접두어
2. **한국어 구문 매칭**: 항목 텍스트가 태스크 설명에 포함
3. **키워드 퍼지 매칭**: 40% 이상 키워드 일치

**Tip**: 항목을 구체적으로 쓸수록 자동 매칭 정확도가 올라갑니다.

## 출력 규칙

1. 대상 repo의 `.doc/` 디렉토리가 없으면 생성
2. 기존 GOALS.md가 있으면 체크 상태(`[x]`)를 절대 변경하지 않음
3. 모든 새 항목은 `- [ ]` (미완료)로 시작
4. UTF-8 인코딩
5. 실제 코드를 읽고 분석한 결과만 작성 — 추측하지 않음
6. 생성 후 항목 수와 요약을 사용자에게 출력
